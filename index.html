Andy Alexander — Linux Systems and Infrastructure

I'm a Linux systems professional with 20+ years of production experience. Since 2022 I've run that same discipline at home: designing, breaking, fixing, and documenting real infrastructure. Everything here is real and running — Proxmox across two sites, ZFS storage on TrueNAS SCALE, OPNsense edge routing over XGS-PON fiber, a WireGuard overlay network, redundant DNS, and automated verified backups.

Live right now: tasks.greenbean.org — a Postgres-backed app on a 3-node k3s cluster, provisioned by Terraform + Ansible, monitored by Icinga2, and served over a self-managed Nginx/Let's Encrypt reverse proxy. Open it, add a task, watch the status panel in the corner.

Selected work

  • Provisioned a 3-node Kubernetes (k3s) cluster with supporting PostgreSQL and Icinga2 hosts entirely via Terraform and Ansible, deploying a containerized Flask/PostgreSQL application exposed publicly at tasks.greenbean.org over a self-managed Nginx/Let's Encrypt reverse proxy
  • Diagnosed and resolved cross-stack failures spanning a Kubernetes scheduler deadlock under strict topology-spread constraints, a kubelet crash loop tied to Linux user-namespace device restrictions, and a Postgres privilege-scoping gap silently blocking application writes
  • Root-caused and resolved a full hypervisor hang on the primary Proxmox host, traced to a wedged USB controller shared with UPS monitoring
  • Diagnosed a same-host bridge networking bug that silently dropped one specific VM-to-VM TCP flow despite clean firewall/VLAN/FDB state at every layer checked; workaround routes the flow through the firewall instead (root cause still open)
  • Closed out an intermittent host scare on the primary Proxmox host with a full memory/MCE/RAS/EDAC investigation — no hardware fault confirmed, with a documented recurrence-testing plan
  • VLAN segmentation — flat 10.0.0.0/24 rebuilt into a segmented VLAN network (10.79.x.x) across the core switch, OPNsense, both Proxmox hosts, and the AP
  • 30TB storage migration: mdadm RAID5 → TrueNAS SCALE / ZFS RAIDZ1 with PCIe SATA passthrough
  • WireGuard hub-and-spoke VPN — cloud-hosted hub, multi-site subnet routing, roaming clients
  • Automated restic backup pipeline across three Proxmox nodes, firewall infrastructure, and home automation — 90-day retention, scheduled integrity verification, off-site replication to Oracle Cloud
  • Replaced upstream DNS forwarding with per-host recursive, DNSSEC-validating Unbound resolvers on both Pi-holes
  • Migrated availability monitoring off broken unauthenticated Pi-hole checks to authenticated Push-based monitors after a Pi-hole v6 auth change
